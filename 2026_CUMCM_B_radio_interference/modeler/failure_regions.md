# Likely Failure Regions

1. **近似平行交会**：交会角过小造成定位区域长轴爆炸；应主动换观测点而非继续同方向采样。
2. **半平面空集**：不同地点 bounded error 约束出现数值矛盾，可能是边界舍入/实现错误/数据异常。保留异常并允许1e-8量级数值容差，不得随意放大误差带。
3. **源极近**：示向度存在但距离可能只略高于5 m；大步移动会越过目标。策略需先尝试低成本清除或短步探测。
4. **全向边界源 + R=1000**：任何依赖平均接收半径的稀疏覆盖都会漏源。
5. **空频道多（N=10）**：为了证明不存在，需完成更多全域覆盖，成为Q3 worst-case。
6. **Q4定向盲区**：任何单侧巡检线都可能被某个源的180°盲半平面完全避开。
7. **目标圆边界**：Q4包围网格必须向圆外扩展，否则圆边缘点没有局部凸包围。
8. **API异常**：accepted=false、HTTP错误、接口直接关闭、现实时间不足均必须进入 anomaly log。
