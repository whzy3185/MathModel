# Modeling Brief v0.1

## 一、赛题总体目标

在半径 1800 m 的已知目标圆域内，利用带 ±1° 方位误差、1000-1500 m 未知接收半径的便携测向设备，建立从**交会定位几何**到**第二检测点设计**，再到**多干扰源自主搜索、定位、清除**的完整方法。Q3 只含全向干扰源；Q4 同时包含全向和未知发射方向的定向干扰源。总目标是在确保全部目标被清除的前提下，尽量降低“移动 + 切频 + 检测 + 光学定位 + 清除”的总虚拟时间，并保证算法可通过官方 HTTP+JSON 模拟器复现。

---

## 二、Problem Map

| 问题 | 现实任务 | 数学任务分类 | 关键输入 | 关键输出 | 核心难点 |
|---|---|---|---|---|---|
| Q1 | 多点方位交会 | computational geometry / set-membership estimation | 检测点坐标、每点示向度、±1°误差 | 定位凸多边形、直径、覆盖判定 | 环状角度、半平面交、无界/空集、数值稳定性 |
| Q2 | 选第二检测点 | experimental design / robust optimization | 第一点、第一次示向度、接收半径先验 | 第二点策略与候选区域 | 交会角质量、二次可探测性、移动代价、未知距离 |
| Q3 | 全向多源搜索清除 | active sensing + routing + sequential decision | 20频道、10-16个源、全向、隐藏位置/半径 | 搜索-定位-清除策略、正式测试统计 | 未知源数、频道缺失、覆盖保证、定位精度与行程权衡 |
| Q4 | 混合全向/定向多源 | robust active sensing / coverage / routing | Q3 + 未知定向源及方向 | 对方向盲区稳健的搜索清除算法 | no_signal 三义性、任意半平面覆盖、二次测量可能掉出波束 |

### 跨问题依赖

Q1 提供统一的**集合交会定位器**；Q2 提供**主动选择下一检测点**的方法；Q3 将二者嵌入多频道任务调度；Q4 进一步把“检测可见性”从圆盘改为未知方向半圆盘，并需要更强的空间覆盖与对称探测机制。因此整体 Storyline 是：

**误差集合几何 -> 主动测量设计 -> 全向多源调度 -> 定向不确定性鲁棒化。**

## 三、Requirement Matrix（摘要）

完整矩阵见 `requirement_matrix.csv`。

### Q1
- Input：若干检测点 S_i=(x_i,y_i)，对应同一干扰源示向度 theta_i。
- Output：定位区域 P、直径 D=max_{p,q in P}||p-q||，并判断是否存在直径为 D 的圆覆盖 P。
- Required evidence：半平面表示、顶点生成、可行性/有界性检查、直径对测试、反例。
- Validation：构造已知几何、随机点落入约束检查、数值扰动测试。

### Q2
- Input：S1 和第一次示向度 theta_1（全向源）。
- Output：可计算的候选区域 C 与推荐第二点 S2*。
- Objective：提高交会角，同时保持较高二次接收概率并控制移动成本。
- Validation：对第一可行源区域离散积分/Monte Carlo，比较固定垂直偏移 baseline。

### Q3
- Input：隐藏的 10-16 个全向源，频道互异。
- Output：在线动作序列，全部清除；统计清除比例、平均定位清除时间、程序运行时间。
- Validation：离线随机环境 + 官方演练；三次正式测试只使用真实日志回填。

### Q4
- Input：Q3 + 未知定向源与未知定向方向。
- Output：能处理波束盲区的搜索/定位/清除在线策略。
- Validation：方向角全覆盖压力测试、极端边界源、官方演练与三次正式测试。

## 四、数据/附件审计

本题不是传统静态数据集题，当前输入主要是**物理规则 + API 契约**，正式案例真值在官方模拟器中隐藏。

### 已确认的一致规则

1. 目标圆半径 1800 m，坐标原点在圆心。
2. 20 个频道，每频道最多一个源；每局总源数 10-16。
3. 示向误差固定地点不因重复测量变化，跨地点才体现统计规律，因此**同点重复测向没有降低误差的价值**。
4. 有效接收半径各源独立、位于 1000-1500 m，API 不返回。
5. /measure 的合法动作时间为移动时间 + 可选 1 s 切频 + 5 s 检测。
6. /clear 的合法动作时间为移动时间 + 3 s 光学定位 +（若成功）2 s 激光清除；不改变当前测向频道。
7. no_signal 不能区分“无源/超距/定向盲区”。
8. 正式测试真值不显示，必须依赖行为日志与机器狗自身日志形成证据链。

### 当前不可验证项

- 官方模拟器隐藏案例的真实随机分布机制。
- 官方服务器侧方位误差的具体随机生成分布（题面只给范围 [-1°,1°]，不能擅自假设正态）。
- 正式测试的案例编码和结果。

这些项目不会在论文中虚构；将通过演练日志补证。

## 五、Candidate Model Pool

### Q1：交会定位

**Primary：凸半平面交 + 顶点枚举 + 直径对。**

每个示向度 theta_i 产生一个开角 2δ（δ=1°）的前向楔形区域 W_i。将两条边界射线写成两个线性半平面，定位区域为

P = intersection_i W_i。

这是凸集；若有界且非空，则为凸多边形。通过边界线两两求交并筛选满足全部半平面的点即可生成顶点，再对凸包顶点求最大点对距离。

Alternative：通用 half-plane intersection（按极角排序，双端队列，O(n log n)）。

Baseline：把每条示向度当精确直线做最小二乘交点；该方法忽略 ±1° 的集合不确定性，不可作为主方法。

### Q2：第二点选择

**Primary：可探测性-交会角-移动代价三目标主动测量设计。**

第一次测量给出可行源集合 Omega_1。对候选 S2 定义：

- 探测保证/概率项：S2 到候选源点的距离是否 <=1000 m（1000 是最小接收半径，满足则不依赖未知真实半径即可保证全向源可被检测）。
- 几何项：两条视线交会角 alpha，使用 sin^2(alpha) 作为无量纲质量，90° 最优、近平行最差。
- 路程项：||S2-S1||/5。

推荐最大化离散鲁棒评分：

J(S2)=E_{G in Omega_1}[I(||S2-G||<=1000) sin^2 alpha] - lambda*d(S1,S2)/1000。

Alternative：minimax，最大化 Omega_1 上较低分位数交会角质量。

Baseline：从 S1 沿第一次示向度法线固定移动 L 后测量。

### Q3：全向源

**Primary：覆盖保证的多频道发现 + 集合交会定位 + 事件驱动清除 + 路由重规划。**

核心结构：
1. 对仍未确认的频道，在一组可覆盖目标圆的“哨点”进行批量扫描；
2. 一旦某频道得到 direction/near，创建 TargetState；
3. 用 Q1 的楔形交实时更新定位集合；
4. 当存在一点 c 使整个定位区域落入 B(c,20)（实际代码用所有多边形顶点到 c 的最大距离 <=20）时直接 /clear；
5. 否则用 Q2 选取下一信息增益高的检测点；
6. 多目标情况下按“预计新增清除收益 / 额外虚拟时间”重排下一动作；
7. 对尚未发现的频道继续完成覆盖证明，直到全部频道已被证明无源或源已清除；若已清除 16 个则可立即结束，因为源数上限为16。

Baseline：固定网格逐点扫20频道，全部发现后逐个三角定位。

Alternative：纯逐频道搜索；由于会重复大量行程，预计劣于“空间点批量扫频道”。

### Q4：混合定向源

**Primary：三角网格的方向无关发现保证 + 对称侧探测。**

关键几何事实：若某源 G 位于三角形 ABC 内，且 |GA|,|GB|,|GC|<=1000，则对任意未知定向方向（有效覆盖是经过 G 的一个闭半平面），A/B/C 不可能全部位于无信号半平面；至少一个顶点必在有效覆盖半平面中。因此，将目标圆嵌入边长 <=1000 m 的三角网格并扫描网格顶点，可为定向源提供方向无关的“至少一次可见”保证。边界处允许网格顶点在目标圆外，因为接口允许机器狗提交目标区域外位置。

首次发现定向源后，第二次探测采用“向源方向推进 + 左右对称侧探”机制：沿当前示向度方向推进以保持接近源，再对两侧候选点按代价顺序尝试。若首次可见方向恰在定向覆盖边界，一侧可能失信号，但对称另一侧仍有机会进入覆盖；所有 no_signal 均保留为可见性约束而非删除目标。

Baseline：直接复用 Q3 的全向圆盘覆盖哨点。该方案不能保证任意定向方向下被发现，故只能作为反例 baseline。

## 七、Strong Assumptions

1. **SA-01（Q2 源位置先验）**：若需要把 Omega_1 上积分变成期望，初版使用“沿第一可行区域等权离散”作为设计先验。题面没有给真实空间分布，因此论文最终必须同时报告 minimax/敏感性结果，避免把该先验写成事实。
2. **SA-02（离线方位误差）**：离线模拟器若用 Uniform[-1°,1°] 仅用于压力测试，不代表官方误差分布。确认性结论必须对 adversarial bounded error 或多种分布重复验证。
3. **SA-03（Q3 搜索覆盖点）**：初版采用对最小接收半径1000 m的保守覆盖，可能牺牲平均时间；后续通过演练数据判断是否能安全采用概率型/自适应提前终止。
4. **SA-04（Q4 三角网格）**：方向保证基于定向覆盖恰为闭半平面（±90°）且网格相关顶点均在有效接收半径内；这是题面规则，不是经验猜测，但网格边长必须严格 <=1000 m。

---

## 八、Likely Failure Regions

- Q1：示向楔几乎平行 -> 交会区域很长甚至无界；检测误差导致半平面无公共交 -> 空集；边界线近共线 -> 数值不稳定。
- Q2：源极近或位于第一可行段端点；候选点虽然几何角好但超出真实接收半径；过度追求90°导致移动太远。
- Q3：边界源、接收半径恰1000、源数=10使“未发现频道证明”成本最大；多个已发现目标方向相反导致清除路由频繁回撤。
- Q4：定向源正好把已有探测点压在覆盖边界；目标位于圆边界附近，若网格未向圆外扩展则无法形成包围三角形；对 no_signal 错误解释会造成永久漏检。
- API：程序现实时间不足、接口尚未开放、accepted=false、网络重试 request_id 使用错误、正式日志异常膨胀。

---

## 九、最值得探索的创新点

1. **误差集合而非概率点估计**：把 ±1° 直接作为几何可行域，定位结果天然可解释并能给清除半径的严格触发条件。
2. **“直径不等于覆盖圆”判别**：Q1 不只计算 D，还给出由直径对中点唯一确定的覆盖圆判据，避免常见错误。
3. **Q2 信息-可见性-行程统一评分**：不是机械取90°，而是在最小接收半径约束下做主动实验设计。
4. **Q4 三角网格半平面可见性定理**：利用“定向覆盖=180°闭半平面”与“点在局部三角形凸包内”构造方向无关发现保证。
5. **清除触发由集合半径决定**：定位区域一旦能被20 m圆覆盖即可直接清除，无需继续把点估计做得更精。

## 十、Experiment Plan 摘要

### E1 Q1 正确性
- 构造两站/三站已知楔形；验证所有输出顶点满足全部半平面。
- 随机生成真实 G、检测点与 bounded error，检查 G 是否始终位于定位集合。
- 近平行压力测试、空集测试、无界测试。
- 覆盖圆反例：等边三角形直径 D 的外接圆半径 D/sqrt(3)>D/2，因此“直径为D的圆”不一定覆盖任意直径为D的区域。

### E2 Q2 策略比较
- 第一可行区域采样 200-1000 个候选 G。
- 比较：固定垂直偏移、固定前进+侧移、主动评分最优点。
- 指标：二次保证检测率（d<=1000）、sin(alpha) 分位数、两次测量后定位区域直径、移动虚拟时间。

### E3 Q3 离线 Monte Carlo
- 源数 N in {10,...,16}；位置覆盖中心/边缘/聚集/均匀；R in [1000,1500]。
- 方位误差：Uniform、截断高斯、adversarial endpoints 三类。
- Baseline vs Primary，至少100个随机案例、固定种子集。
- 指标：清除率、平均定位清除时间、measure次数、总移动距离、失败/超时率。

### E4 Q4 方向压力测试
- 在 E3 基础上随机给定向比例0-100%与方向；额外穷举若干边界方向。
- 验证三角网格的首次发现保证；对 no_signal 分支做覆盖测试。

### E5 官方演练/正式
- 官方演练用于确认接口与真实生成机制；失败运行必须进入 anomaly_log.csv。
- 三次正式测试只在策略冻结后执行，原名加密日志直接存 `coder/results/formal_logs/`，并由解析器生成表1。

## 十一、主要风险

1. 官方模拟器只能在参赛电脑本机回环地址访问，当前云端工作区不能直接触发 localhost 正式测试。
2. 题目不提供方位误差的概率分布，只能使用有界误差结论作为强证据，分布假设只能做实验性辅助。
3. “确保全部清除”与“平均时间短”天然冲突：未发现频道需要保守覆盖证明，尤其 N=10 时空频道最多。
4. Q4 为任意方向建立强保证需要更多扫描节点，可能造成较大行程；需通过演练决定最终在保证与平均性能之间如何折中。
